How to use Circuit Mentor

What it does: you write a simple LED circuit as text. Circuit Mentor finds wiring mistakes, explains why each one is a problem, and tells you how to fix it.

What it does not do: it is a checker and tutor, not a simulator. To watch a circuit run, use the free Falstad simulator button on the first tab.

Step by step

  1. Open the Analyze circuit tab.
  2. Choose a template, or type your own circuit in the box.
  3. Press Analyze.
  4. Read each problem. Why it matters explains the mistake. How to fix tells you what to change.
  5. Change the circuit text and press Analyze again. Repeat until it says "Circuit looks good!"
  6. Optional: press Open simulator (Falstad) and build the fixed circuit there to see it work.

How to write a circuit

One component per line: name, first node, second node, value. A node is just a name for a connection point. Two pins with the same node name are joined by a wire.

V1 VCC GND 5      battery: + side, - side, 5 volts
R1 VCC N1 330     resistor between VCC and N1, 330 ohm
D1 N1 GND         LED: anode to N1, cathode to GND

The first letter of the name tells the tool what it is: V = battery, R = resistor, D = LED.

Mistakes it can find

  • Short circuit: both battery terminals are on the same node.
  • No resistor: an LED has no resistor to limit the current.
  • Reversed LED: the LED is connected the wrong way round.
  • Floating node: a connection that goes nowhere, so the loop is open.

The other tabs

  • Scan photo (online only): needs internet and a Claude sign-in, and does not work in the offline file. Choose a photo of a circuit, press Scan, check the text it produces, then press Analyze.
  • Project notes: a summary of the project and answers to likely questions.
  • Standard circuits: 5 textbook circuits (voltage divider, transistor switch, RC filter, rectifier, op-amp). Pick one, type your values, and read the result and common mistakes.
  • Challenge mode: a practice generator that makes a new random resistor question every time, plus 4 short puzzles. Tap an answer, and open the hint if you are stuck.
  • Resistor calculator: enter supply voltage, LED voltage and current. It gives the resistor value and the next standard size.

Project notes

Circuit Mentor | Hack Sphere Hackathon, 10/10/2026 | P Himaja, ECE

What it is

A free, beginner-friendly tool for ECE students. You type a simple LED circuit as text, and it finds wiring mistakes, explains why each one is a problem, and shows the fix. It is a checker and tutor, not a simulator. For simulation it links to the free Falstad simulator.

Features

  • 4 error checks: short circuit, missing resistor, reversed LED, open (floating) node.
  • Standard circuits: voltage divider, transistor switch, RC filter, rectifier, inverting op-amp, each with a calculator and common mistakes.
  • Challenge mode: a random practice generator plus 4 puzzles with hints.
  • Resistor calculator with the next standard value.
  • Scan photo (online only): reads a photo of a circuit and fills in the text for you to check. Needs internet and a Claude sign-in.
  • Works offline: everything except Scan photo. One file, no install, no data collected.

How it works

The text is read line by line into components and nodes. Four logic rules run on those nodes. An LED is flagged if there is a route from battery + to battery - through it with no resistor in the way, and a node that appears only once is an open end. Each error type has a stored explanation and fix. It is a rule-based expert system: reliable, instant, and every answer can be explained.

How I built it

I defined the problem from my ECE experience and chose the four common errors. I built the checker with an AI assistant, tested it in Google Colab with a correct circuit and wrong ones, then turned it into a single web page. After my brother reviewed it, I simplified the challenge wording, added colours and added the manual.

Likely judge questions

  • Is it really AI? The checker is rule-based. The rules copy how a teacher spots common mistakes. The photo scan uses an AI vision model online, and an AI chat layer is a next step.
  • Difference from Tinkercad or Falstad? They simulate. This diagnoses and teaches why, and links to Falstad.
  • How accurate is it? Accurate for the 4 error types it covers. It does not claim more.
  • How would you scale it? More rules (transistor, capacitor polarity, op-amp), drawing input, an AI chat layer, a mobile app.
  • Why did you build it? I faced these errors while troubleshooting circuits in my internship and my Arduino fire fighter robot project.

Limits (say these first)

The checker understands only batteries, resistors and LEDs, and checks wiring logic, not voltages. The reversed-LED rule catches direct connections to the battery only. Scan is online only and can misread a photo, so the text must be checked.
